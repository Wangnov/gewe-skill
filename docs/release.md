# Release

`gewe-skill` uses GitHub as the release build source. Do not build release binaries on the OCI server.

## Tools

- `cargo-release` manages version commits and tags.
- `cargo-dist` builds GitHub Release artifacts and installers.
- GitHub Actions builds Linux, macOS, Windows, glibc, and musl release archives.

## Targets

The release workflow builds:

- `x86_64-unknown-linux-gnu`
- `x86_64-unknown-linux-musl`
- `aarch64-unknown-linux-gnu`
- `aarch64-unknown-linux-musl`
- `x86_64-apple-darwin`
- `aarch64-apple-darwin`
- `x86_64-pc-windows-msvc`

The OCI host should use `aarch64-unknown-linux-musl` when possible, or `aarch64-unknown-linux-gnu` if musl has a runtime issue.

## Candidate gate

Before pushing a release tag, run the `Release candidate` workflow manually with the intended tag, for example:

```bash
gh workflow run "Release candidate" --ref main -f tag=v0.1.0
```

The candidate workflow builds Linux glibc and musl archives on x64 and ARM64 runners, extracts the release archives, runs `gewe-skill --help`, starts `gewe-skill-memory`, and checks `/healthz`.

## Release tag

Create and push a version tag:

```bash
git tag v0.1.0
git push origin v0.1.0
```

The `Release` workflow generated by `cargo-dist` will publish the GitHub Release and upload installers plus platform archives.

## Updating OCI

Use the installer from a checked-out repo or source archive. It downloads GitHub Release assets, verifies sha256 files, installs binaries, installs systemd units and timers, and preserves `/opt/gewe-skill-memory/config/gewe-skill-memory.env`:

```bash
sudo GEWE_SKILL_VERSION=v0.1.18 scripts/install-oci-memory-release.sh
```

The installer defaults to the host architecture and glibc Linux targets:

- `aarch64-unknown-linux-gnu` on ARM64 hosts
- `x86_64-unknown-linux-gnu` on x64 hosts

Override with `GEWE_SKILL_TARGET` only when needed.

Manual fallback:

```bash
version=v0.1.0
target=aarch64-unknown-linux-musl
tmpdir="$(mktemp -d)"

gh release download "$version" \
  --repo Wangnov/gewe-skill \
  --pattern "gewe-skill-cli-${target}.tar.xz" \
  --pattern "gewe-skill-memory-${target}.tar.xz" \
  --dir "$tmpdir"

tar -xJf "$tmpdir/gewe-skill-cli-${target}.tar.xz" -C "$tmpdir"
tar -xJf "$tmpdir/gewe-skill-memory-${target}.tar.xz" -C "$tmpdir"

sudo install -o root -g root -m 0755 "$tmpdir/gewe-skill-cli-${target}/gewe-skill" /opt/gewe-skill-memory/bin/gewe-skill
sudo install -o root -g root -m 0755 "$tmpdir/gewe-skill-memory-${target}/gewe-skill-memory" /opt/gewe-skill-memory/bin/gewe-skill-memory
sudo systemctl restart gewe-skill-memory.service
```

Keep `/opt/gewe-skill-memory/config/gewe-skill-memory.env` and `/opt/gewe-skill-memory/data` in place.
